이력서 빌더 퍼블리싱 산출물

사이트 CSS 를 수정하거나 추가할 때 화면으로 확인하고 저장하는 곳입니다.

산출물 추가 방법

  1. css/ 의 CSS 를 수정하거나 새 파일을 추가합니다. resume-web 의 static/css/ 와 구조가 같아서 파일을 그대로 옮길 수 있습니다.
  2. pages/changes/_template.html 을 복사해 yyyyMMdd-이름.html 로 저장하고, 변경 내용과 미리보기를 채웁니다. 기존 컴포넌트 · 화면 페이지가 바뀌면 함께 고칩니다.
  3. publish/catalog.js 의 해당 그룹에 페이지를 등록하면 이 목록에 나타납니다.
  4. 확정되면 바뀐 CSS 를 resume-web 의 같은 경로로 옮기고, 산출물의 반영 상태를 바꿉니다.
